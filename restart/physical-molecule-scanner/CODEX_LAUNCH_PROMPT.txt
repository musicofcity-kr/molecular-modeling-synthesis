Physical Molecule Scanner를 Graph-first 방식으로 개발한다.

먼저 다음 4개 파일을 읽어라.

1. `physical-molecule-scanner/AGENTS.md`
2. `physical-molecule-scanner/PROJECT_INTENT.md`
3. `physical-molecule-scanner/WORKFLOW_GRAPH.md`
4. `physical-molecule-scanner/CURRENT_NODE.md`

중요:
- 전체 그래프를 이해하되 실제 작업은 CURRENT_NODE의 ACTIVE NODE 하나만 수행한다.
- 현재 노드 PASS 전에는 다음 노드를 선행 구현하지 않는다.
- 실패하면 현재 노드 안에서 수정한다.
- 기술적으로 가능한 기능을 미리 추가하지 않는다.
- 부모 프로젝트는 필요 없이 수정하지 않는다.

현재 ACTIVE NODE는 N0 — Repository Map이다.

즉시 대규모 코딩을 시작하지 말고 기존 저장소를 실제로 분석하여
`graph-output/N0_REPOSITORY_MAP.md`를 생성하라.

완료 후:
- N0 PASS/FAIL
- PASS/FAIL 근거
- 확인된 재사용 요소
- 위험 요소
- 다음 노드 제안

만 보고하고 멈춰라.

N1은 아직 시작하지 마라.
