# PROJECT_INTENT.md — 프로젝트 의도

## 1. 우리가 만들려는 것

학생이 분자모형 키트를 이용해 실제 분자모형을 만든 뒤 사진을 촬영하면,
프로그램이 원자와 결합 후보를 분석하고 학생이 이를 확인·수정한 후
화학적으로 검증된 3D Reference 구조를 생성하여 비교·탐색할 수 있게 한다.

최종 학습 흐름은 다음과 같다.

**직접 제작 → 촬영 → 확인/수정 → 구조 검증 → 3D 탐색 → 측정 → 비교 → 설명 수정**

## 2. 이 프로젝트의 핵심 가치는 '사진 인식' 자체가 아니다

목표는 사진을 멋진 3D 모델로 바꾸는 기술 데모가 아니다.

학생이 자신이 만든 모형과 과학적으로 타당한 Reference 구조의 차이를 발견하고,
그 차이를 분자구조 개념으로 설명하도록 돕는 것이 핵심이다.

즉,

**Physical → Digital → Scientific Reference → Reflection**

의 학습 사이클을 만든다.

## 3. 학생이 최종적으로 할 수 있어야 하는 행동

학생은 프로그램을 사용한 뒤 다음을 할 수 있어야 한다.

- 사진에서 프로그램이 인식한 원자를 확인하거나 수정한다.
- 원자 사이 결합을 확인하거나 수정한다.
- 자신이 만든 분자의 정체 후보를 확인한다.
- 3D 분자를 회전·확대·축소하며 구조를 관찰한다.
- 원자를 선택하여 Reference 구조의 결합길이와 결합각을 확인한다.
- 자신이 만든 Physical Model과 Scientific Reference를 비교한다.
- 구조 차이를 VSEPR, 전자영역, 분자 기하 등의 개념과 연결한다.
- 필요하면 자신의 모형이나 설명을 다시 수정한다.

## 4. 과학적으로 반드시 분리해야 하는 두 구조

### Physical Model

학생이 플라스틱 분자모형 키트로 실제 제작한 구조.

여기서 관찰할 수 있는 것은 주로:
- 원자 종류 후보
- 연결 관계 후보
- 상대적 공간 배치
- 모형에서 보이는 대략적 각도
- 제작상의 오류

### Scientific Reference

검증된 molecular graph 및 신뢰 가능한 구조 데이터/계산에서 얻은 구조.

여기서는:
- 분자식
- 결합 관계
- 결합차수
- 3D 좌표
- 결합길이
- 결합각
- 이면각
- 구조적 특징

등을 제공할 수 있다.

두 구조를 섞지 않는다.

## 5. 초기 MVP의 의도적 제한

초기 원자:
H, C, N, O, F, Cl

초기 대표 분자:
H2, O2, N2, H2O, NH3, CH4, CO2, C2H6, C2H4, CH3OH

초기 버전은 범용 분자 인식기가 아니다.

교육용 분자키트의 제한된 환경을 활용하여
**색상/형태 기반 후보 탐지 + 학생 확인(Human-in-the-loop)** 방식부터 시작한다.

사진 한 장에서 완전한 3D 좌표를 복원하는 것을 MVP 목표로 삼지 않는다.

## 6. 성공 기준

이 프로그램이 성공했는지는 다음 질문으로 판단한다.

> 학생이 프로그램 사용 후 분자의 3차원 구조와 자신이 만든 모형의 차이를 이전보다 더 잘 설명할 수 있는가?

이 질문에 직접 기여하지 않는 기능은 우선순위가 낮다.
