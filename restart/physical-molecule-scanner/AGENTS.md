# AGENTS.md — Thin Guardrail

이 폴더는 기존 분자구조 모델링 프로그램 안에서 독립적으로 개발하는
`Physical Molecule Scanner` 실험 영역이다.

## 최상위 우선순위

교육적 가치 > 화학적 정확성 > 학생 UX > 기존 프로젝트 안정성 > 기술적 완성도

## 반드시 지킬 최소 규칙

1. `CURRENT_NODE.md`에 지정된 **현재 노드 하나만** 작업한다.
2. 현재 노드의 PASS 조건을 만족하기 전에 다음 노드를 선행 구현하지 않는다.
3. 실패하면 다음 노드로 가지 말고 현재 노드 안에서 원인을 수정한다.
4. 검증되지 않은 화학정보를 사실처럼 출력하지 않는다.
5. 학생의 Physical Model과 Scientific Reference를 데이터와 UI에서 구분한다.
6. 사진의 픽셀 거리나 분자키트의 막대 길이를 실제 Å 결합길이로 출력하지 않는다.
7. AI/비전 추정을 최종 화학 사실처럼 확정하지 않는다. 불확실하면 사용자 확인을 거친다.
8. 기존 부모 프로젝트는 기본적으로 읽고 재사용 가능성을 판단하되, 필요 없이 수정하지 않는다.
9. 현재 노드에 필요하지 않은 DB, 로그인, 관리자, AR/VR, 자체 AI 학습, 대규모 리팩터링을 추가하지 않는다.
10. 작동하지 않는 기능, DEMO, 추정값을 완성 기능처럼 보고하지 않는다.
11. 실제로 확인한 사실과 추정을 구분한다.
12. 출력물의 품질은 코드량이 아니라 현재 노드의 PASS 조건으로 판단한다.

## 작업 방식

작업 전:
- `PROJECT_INTENT.md`
- `WORKFLOW_GRAPH.md`
- `CURRENT_NODE.md`

를 읽는다.

작업 후:
- 현재 노드의 OUTPUT을 만든다.
- PASS 조건을 검증한다.
- PASS/FAIL 근거를 짧게 보고한다.
- PASS여도 다음 노드를 임의로 시작하지 않는다.
